# TAOS Logistics Analytics

End-to-end logistics analytics solution built using **Power BI**, **Microsoft Fabric**, **SQL**, and **Git** to monitor and optimize delivery operations, courier performance, and Return to Origin (RTO) metrics.

## Key Features & Coverage
- **RTO % Analysis:** Track Return to Origin rates across regions, couriers, and order segments to identify high-risk return patterns.
- **Courier Performance:** Evaluate SLA adherence, on-time delivery rates, and transit durations across logistics partners.
- **Pincode Analysis:** Geographic drill-down by pincode to pinpoint delivery bottlenecks and serviceability gaps.
- **Partner Comparison:** Side-by-side benchmarking of courier partners on cost, speed, and reliability.
- **Delivery Exceptions:** Root-cause tracking of failed deliveries, delays, and operational exceptions.

## Architecture & Optimization
- **Automated Data Pipelines:** Built automated **Microsoft Fabric API** data pipelines for reliable, scheduled data ingestion and transformation.
- **Data Model Optimization:** Achieved **90% data model optimization** through star-schema modeling, query folding, and efficient DAX measures.
- **Version Control:** Managed SQL scripts, pipeline configurations, and Power BI artifacts using **Git**.

## Tech Stack
- **BI & Visualization:** Power BI, DAX
- **Data Platform & ETL:** Microsoft Fabric, Fabric API Pipelines
- **Database & Querying:** SQL
- **Version Control:** Git
